Fuite de données La Maison Pour Tous : environ 8 000 noms de locataires publiés

Une fuite de données attribuée à La Maison Pour Tous (LMPT), coopérative immobilière française, est revendiquée ce samedi 5 septembre 2026 sur un forum cybercriminel. Un utilisateur sous le pseudonyme ChimeraZ affirme publier environ 8 000 entrées provenant de lmpt-coop.fr. Les données diffusées seraient limitées aux noms de locataires.

Une base de données attribuée à La Maison Pour Tous (LMPT) a été publiée sur un forum cybercriminel.

L'utilisateur à l'origine de la publication, sous le pseudonyme ChimeraZ, affirme diffuser des informations concernant des locataires de lmpt-coop.fr.

La publication est datée du :

5 septembre 2026

Le fichier est annoncé avec une taille d'environ :

275 Ko

Les données sont proposées au format :

CSV

Le titre de la publication mentionne environ 8 000 entrées et précise explicitement :

« ONLY NAMES »

Autrement dit, l'auteur affirme que cette publication contient uniquement des noms.

Environ 8 000 entrées attribuées à La Maison Pour Tous

La publication est présentée sous le titre :

« 8K LMPT-COOP.FR (ONLY NAMES) »

L'auteur affirme publier les données de locataires de lmpt-coop.fr.

À ce stade, la capture ne fournit pas un décompte exact des enregistrements. Le chiffre de 8 000 correspond donc au volume annoncé par l'auteur de la publication.

Il n'est pas possible de déterminer à partir de cette seule capture si chaque entrée correspond à une personne distincte.

Quelles données sont présentes dans la fuite ?

Contrairement à d'autres fuites pouvant contenir des coordonnées complètes, l'auteur précise ici que les informations publiées seraient limitées aux noms des locataires.

L'échantillon visible comporte notamment :

  • un identifiant numérique ;
  • une civilité ;
  • un nom associé à un locataire ou foyer.
L'échantillon contient donc effectivement une information permettant d'identifier nominativement une personne ou un foyer.

Pour des raisons de confidentialité, les informations personnelles visibles dans l'échantillon ne sont pas reproduites dans cet article.

Aucun e-mail ou numéro de téléphone visible

Les éléments publiés doivent être distingués d'une base clients contenant des coordonnées complètes.

Sur l'échantillon actuellement visible, aucune des catégories suivantes n'apparaît :

  • adresse e-mail ;
  • numéro de téléphone ;
  • adresse postale ;
  • mot de passe ;
  • donnée bancaire ;
  • pièce d'identité ;
  • date de naissance.
Il n'est donc pas possible d'affirmer que ces informations ont été compromises.

La revendication visible concerne spécifiquement une liste présentée comme contenant uniquement des noms.

Qui est La Maison Pour Tous ?

La Maison Pour Tous, associée au domaine lmpt-coop.fr, est présentée dans la publication comme une coopérative française de logement social.

La base diffusée est décrite par son auteur comme contenant des informations relatives aux locataires de l'organisme.

La nature des informations visibles dans l'échantillon apparaît cohérente avec cette description, sans permettre pour autant de confirmer indépendamment l'origine technique du fichier.

Comment les données ont-elles été récupérées ?

À ce stade, la méthode utilisée pour obtenir ces données reste inconnue.

La publication visible ne fournit aucun détail technique concernant leur origine.

Il n'est donc pas possible de déterminer si les informations proviennent :

  • d'une intrusion dans les systèmes informatiques ;
  • d'un compte compromis ;
  • d'une vulnérabilité ;
  • d'une mauvaise configuration ;
  • d'un prestataire ;
  • d'une ancienne base de données ;
  • ou d'une autre source.
La publication d'un fichier attribué à une organisation ne permet pas, à elle seule, de confirmer une intrusion directe dans son système d'information.

Une cyberattaque contre La Maison Pour Tous est-elle confirmée ?

À ce stade, les éléments disponibles permettent surtout d'établir qu'un utilisateur d'un forum cybercriminel revendique la publication d'une base attribuée à La Maison Pour Tous.

L'échantillon visible contient effectivement un identifiant et une information nominative.

Il ne permet cependant pas de confirmer indépendamment :

  • une intrusion récente dans les systèmes de LMPT ;
  • la méthode utilisée pour récupérer les données ;
  • la date de leur éventuelle extraction ;
  • l'origine exacte du fichier ;
  • l'existence d'autres données compromises.
La date du 5 septembre 2026 correspond à la date de publication sur le forum et non nécessairement à celle d'une éventuelle compromission.

Quels risques pour les personnes concernées ?

Une liste contenant des noms présente généralement un niveau d'exposition inférieur à une base associant identité, coordonnées et informations financières.

Ces informations restent néanmoins des données personnelles lorsqu'elles permettent d'identifier directement ou indirectement des personnes.

Elles pourraient notamment être utilisées pour :

  • identifier des personnes présentées comme locataires ;
  • enrichir d'autres bases de données ;
  • effectuer des recherches complémentaires ;
  • faciliter certaines opérations d'ingénierie sociale ;
  • croiser les informations avec d'autres fuites de données.
Le niveau de risque dépend donc notamment de la possibilité de recouper ces informations avec d'autres sources.

Ce que montre la publication

✅ Une base attribuée à La Maison Pour Tous / lmpt-coop.fr est publiée sur un forum cybercriminel.

✅ La publication est datée du 5 septembre 2026.

✅ L'auteur utilise le pseudonyme ChimeraZ.

✅ Le titre revendique environ 8 000 entrées.

✅ Le fichier est annoncé comme pesant environ 275 Ko.

✅ Le format annoncé est CSV.

✅ L'auteur présente les informations comme concernant des locataires.

✅ La publication précise « ONLY NAMES ».

✅ L'échantillon visible contient un identifiant et une information nominative.

Ce qui reste à déterminer

⚠️ Le nombre exact de personnes concernées.

⚠️ L'origine exacte du fichier.

⚠️ L'ancienneté des données.

⚠️ La date d'une éventuelle exfiltration.

⚠️ Le mode d'obtention des informations.

⚠️ L'existence d'une intrusion dans les systèmes de La Maison Pour Tous.

⚠️ L'existence éventuelle d'autres données récupérées mais non publiées.

⚠️ Une confirmation officielle de l'incident par La Maison Pour Tous.

Conclusion

Une base attribuée à La Maison Pour Tous (LMPT) et présentée comme contenant environ 8 000 entrées a été publiée sur un forum cybercriminel le 5 septembre 2026.

L'utilisateur ChimeraZ affirme diffuser des informations concernant des locataires de lmpt-coop.fr. Le fichier, annoncé au format CSV, représenterait environ 275 Ko.

La publication précise que les données sont limitées aux noms, et l'échantillon visible contient effectivement une information nominative associée à un identifiant.

Ces éléments étayent donc l'existence d'une publication de données attribuées à La Maison Pour Tous, mais ne permettent pas de déterminer comment elles ont été obtenues ni de confirmer une intrusion directe dans les systèmes de l'organisme.

L'origine exacte du fichier, son ancienneté et le nombre précis de personnes concernées restent à déterminer.
